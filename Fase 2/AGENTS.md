# Agent Operating Rules

This project enforces the following working agreements:

1. **Transparent Execution**: Every action, command, and design decision must be explained clearly before or while executing it.
2. **Conversation Archival**: Every prompt sent by the user and every response returned by the agent must be stored sequentially in `CONVERSATION.md`.
3. **Relative File Paths**: Never use absolute system paths. Always use paths relative to the project root (e.g., `AGENTS.md`, `CONVERSATION.md`).
